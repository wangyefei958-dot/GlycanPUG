# 95轮link — Glycan-Linking Downstream Task

Based on the **best checkpoint at epoch 95** from pre-training in the main folder, this task extracts embeddings and performs classification training on glycan-linking types (N-Linked / O-Linked, etc.).

> 🌐 中文版：[README.md](./README.md)

## Directory Structure

```
95轮link/
├── masktrain_windows_313.py        # ⬅ Moved in from the main folder (external)
├── wurcs_parser_reverse_edge.py     # ⬅ Moved in from the main folder (external)
├── get_embeddings_W0.py            # Extract 1027-dim embeddings
├── glycanW0_classifier.py          # Linking-type classification training
├── embedding_vocab.json            # ⬅ Moved in from the main folder (external)
├── checkpoints/
│   └── best_model_mlm.pt          # ⬅ Moved in from the main folder (95-epoch pre-training weights, external)
├── train/
│   ├── glyconnect_structures.csv              # ⬅ Moved in externally: GlyConnect linking-type raw data
│   ├── glyconnect_structures_with_embeddings.csv  # Generated by get_embeddings_W0.py
│   └── 数量统计.py                              # Count rows and labels per CSV
```

> Files marked ⬅ are **moved in from external sources**: `masktrain_windows_313.py`, `wurcs_parser_reverse_edge.py`, `embedding_vocab.json`, and `checkpoints/best_model_mlm.pt` come from the main folder `MASK/`; `train/glyconnect_structures.csv` is the external GlyConnect dataset. These files are large or are generated products — **not uploaded to GitHub**; they must be placed manually before running.

## Data Description

`train/glyconnect_structures.csv` has one glycan structure per row, containing `GlyTouCan ID`, `glycantype` (linking type, e.g. N-Linked / O-Linked), `IUPAC Condensed`, `WURCS`, and other columns.

## Execution Order

```bash
# Prerequisite: ensure embedding_vocab.json and checkpoints/best_model_mlm.pt are placed in this directory

# 1. Extract embeddings → generates train/glyconnect_structures_with_embeddings.csv
py -3.13 get_embeddings_W0.py \
    --input_dir ./train \
    --output_dir ./train \
    --vocab_path embedding_vocab.json \
    --checkpoint_path checkpoints/best_model_mlm.pt

# 2. Classification training → generates training_results_*/ (model, logs, confusion matrix)
py -3.13 glycanW0_classifier.py --work_dir ./train
```
