# 95轮tax — Taxonomy Downstream Task

Based on the **best checkpoint at epoch 95** from pre-training in the main folder, this task extracts embeddings and performs multi-seed classification training across 8 taxonomic levels (domain → species).

> 🌐 中文版：[README.md](./README.md)

## Directory Structure

```
95轮tax/
├── masktrain_windows_313.py        # ⬅ Moved in from the main folder (external)
├── wurcs_parser_reverse_edge.py     # ⬅ Moved in from the main folder (external)
├── get_embeddings_W0.py            # Extract 1027-dim embeddings
├── glycanW0_classifier.py          # Taxonomy classification training (top-level copy; each seed under finaltrain has its own copy)
├── 总结.py                          # Aggregate F1/AUC metrics across seeds
├── embedding_vocab.json            # ⬅ Moved in from the main folder (external)
├── GlycanW0_metrics.csv            # Generated by 总结.py
├── checkpoints/
│   └── best_model_mlm.pt          # ⬅ Moved in from the main folder (95-epoch pre-training weights, external)
├── split_files/                     # ⬅ Moved in externally: WURCS CSVs split by taxonomic level
│   ├── domain.csv / kingdom.csv / phylum.csv / class.csv
│   ├── order.csv / family.csv / genus.csv / species.csv
│   └── 数量统计.py                  # Count rows and labels per CSV
├── split_files_processed_wurcs/     # Generated by get_embeddings_W0.py (embedding CSVs)
├── finaltrain/                      # Multi-seed final training
│   ├── 新建 文本文档.py             # Batch-run glycanW0_classifier.py in each seed folder
│   ├── 42/                          # Seed 42
│   │   ├── glycanW0_classifier.py   # Same as top-level, only the seed parameter differs
│   │   └── split_files_processed_wurcs/  # ⬅ Manually moved in (copied from top-level)
│   │       └── training_results_<level>/  # Per-level training outputs
│   ├── 58/                          # Seed 58 (same structure)
│   ├── 518/                         # Seed 518
│   ├── 5188/                        # Seed 5188
│   └── 51888/                       # Seed 51888
```

> Files marked ⬅ are **moved in from external sources**: `masktrain_windows_313.py`, `wurcs_parser_reverse_edge.py`, `embedding_vocab.json`, and `checkpoints/best_model_mlm.pt` come from the main folder `MASK/`; `split_files/*.csv` are external data split by taxonomic level. `finaltrain/<seed>/split_files_processed_wurcs/` is manually copied in from the top level. These files are large or are generated products — **not uploaded to GitHub**; they must be placed manually before running.

## Data Description

Each CSV under `split_files/` corresponds to one taxonomic level, containing `glytoucan_id`, `label`, `WURCS`, and other columns, split into train/valid/test. The 8 levels are: domain, kingdom, phylum, class, order, family, genus, species.

## Execution Order

```bash
# Prerequisite: ensure embedding_vocab.json and checkpoints/best_model_mlm.pt are placed in this directory

# 1. Extract embeddings → generates split_files_processed_wurcs/*.csv
py -3.13 get_embeddings_W0.py \
    --input_dir ./split_files \
    --output_dir ./split_files_processed_wurcs \
    --vocab_path embedding_vocab.json \
    --checkpoint_path checkpoints/best_model_mlm.pt

# 2. Manually copy split_files_processed_wurcs/ into each seed folder under finaltrain/
#    Each seed folder already has its own glycanW0_classifier.py (same code, different seed)

# 3. Batch-run classification training across all seeds (recursively finds and executes all glycanW0_classifier.py)
cd finaltrain
py -3.13 "新建 文本文档.py"

# 4. Go back up and aggregate multi-seed metrics → generates GlycanW0_metrics.csv
cd ..
py -3.13 总结.py
```
