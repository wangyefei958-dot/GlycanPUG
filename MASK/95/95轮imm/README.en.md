# 95轮imm — Immunogenicity Downstream Task

Based on the **best checkpoint at epoch 95** from pre-training in the main folder, this task extracts embeddings and performs classification training on glycan immunogenicity data.

> 🌐 中文版：[README.md](./README.md)

## Directory Structure

```
95轮imm/
├── masktrain_windows_313.py        # ⬅ Moved in from the main folder (external)
├── wurcs_parser_reverse_edge.py     # ⬅ Moved in from the main folder (external)
├── get_embeddings_W0.py            # Extract 1027-dim embeddings
├── glycanW0_classifier.py          # Immunogenicity classification training
├── embedding_vocab.json            # ⬅ Moved in from the main folder (external)
├── checkpoints/
│   └── best_model_mlm.pt          # ⬅ Moved in from the main folder (95-epoch pre-training weights, external)
├── error_analysis/
│   └── training_log.txt            # Pre-training log
├── train/
│   ├── imm_stata.csv               # ⬅ Moved in externally: immunogenicity raw data
│   ├── imm_stata_with_embeddings.csv  # Generated by get_embeddings_W0.py
│   └── 数量统计.py                  # Count rows and labels per CSV
```

> Files marked ⬅ are **moved in from external sources**: `masktrain_windows_313.py`, `wurcs_parser_reverse_edge.py`, `embedding_vocab.json`, and `checkpoints/best_model_mlm.pt` come from the main folder `MASK/`; `train/imm_stata.csv` is the external immunogenicity dataset. These files are large or are generated products — **not uploaded to GitHub**; they must be placed manually before running.

## Data Description

`train/imm_stata.csv` has one glycan structure per row, containing `glycan_id`, `glycan` (IUPAC), `species`, `immunogenicity` (0/1), `wurcs`, and other columns.

## Execution Order

```bash
# Prerequisite: ensure embedding_vocab.json and checkpoints/best_model_mlm.pt are placed in this directory

# 1. Extract embeddings → generates train/imm_stata_with_embeddings.csv
py -3.13 get_embeddings_W0.py \
    --input_dir ./train \
    --output_dir ./train \
    --vocab_path embedding_vocab.json \
    --checkpoint_path checkpoints/best_model_mlm.pt

# 2. Classification training → generates training_results_*/ (model, logs, confusion matrix)
py -3.13 glycanW0_classifier.py --work_dir ./train
```
