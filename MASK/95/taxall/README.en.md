# taxall — Taxonomy "All-Taxa" Configuration

Based on the **best checkpoint at epoch 95** from pre-training in the main folder, this task extracts embeddings and performs multi-seed classification training across all taxonomic levels (including superkingdom, 9 levels in total). This directory is the "all-taxa" extended version of `95轮tax`; `finaltrain/` stores the final training results and graph-structure uncertainty analysis.

> 🌐 中文版：[README.md](./README.md)

## Data Description

Each CSV under `split_files/` corresponds to one taxonomic level, containing `glytoucan_id`, `label`, `WURCS`, and other columns. There are 9 levels in total: superkingdom, kingdom, phylum, class, order, family, genus, species (one more — superkingdom — than `95轮tax`).

## Execution Order

```bash
# Prerequisite: ensure embedding_vocab.json and checkpoints/best_model_mlm.pt are placed in this directory

# 1. Extract embeddings → generates split_files_processed_wurcs/*.csv
py -3.13 get_embeddings_W0.py \
    --input_dir ./split_files \
    --output_dir ./split_files_processed_wurcs \
    --vocab_path embedding_vocab.json \
    --checkpoint_path checkpoints/best_model_mlm.pt

# 2. Manually copy split_files_processed_wurcs/ into each seed folder under finaltrain/
#    Each seed folder already has its own glycanW0_classifier.py (same code, different seed)

# 3. Batch-run classification training across all seeds (recursively finds and executes all glycanW0_classifier.py)
cd finaltrain
py -3.13 "新建 文本文档.py"

# 4. Go back up and aggregate multi-seed metrics → generates GlycanW0_metrics.csv
cd ..
py -3.13 总结.py

# 5. (Optional) Graph-structure uncertainty analysis
cd finaltrain
py -3.13 analyze_graph_uncertainty.py
```

## finaltrain Notes

`finaltrain/` stores multi-seed final training results and uncertainty analysis. `新建 文本文档.py` recursively finds and batch-executes all `glycanW0_classifier.py`. `analyze_graph_uncertainty.py` compares graph-structure uncertainty features (doubt-edge ratio, average edge probability, anomer_x, stereo_x, etc.) between "correctly classified vs misclassified" samples, parsing WURCS in multi-process, statistically summarizing each of the 5 seeds, plotting 2x2 bar charts, and performing Mann-Whitney U tests. Outputs are under `uncertainty_graph/`.
