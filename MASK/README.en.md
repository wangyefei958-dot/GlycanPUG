# MASK: Glycan-Structure Graph Neural Network Pre-training & Downstream Species Classification

> 🌐 中文版：[README.md](./README.md)

This project implements an end-to-end pipeline of "WURCS glycan structure → graph neural network masked pre-training → embedding extraction → taxonomic-level classification". The core idea is to parse the WURCS format string of glycans into a heterogeneous graph (big/small nodes + big/small edges), pre-train a heterogeneous GAT with MLM (Masked Language Modeling), then use the pre-trained model to extract 1027-dim graph-level embeddings, and finally train classification heads on 8 taxonomic levels (domain → species).

## Script Descriptions

### 1. `wurcs_parser_reverse_edge.py`
A WURCS format parser. It can be imported as a module by other scripts, but is also **runnable on its own**: it auto-reads the single `dic.csv` in its directory, parses each `WURCS=...` string into a heterogeneous graph structure for GNN input (`big_nodes` monosaccharides / `small_nodes` substituents / `big_edges` inter-monosaccharide glycosidic bonds / `small_edges` monosaccharide-substituent connections), and performs two passes (first collecting the vocabulary, then filtering low-frequency/uncertain items). Running it directly produces:
- `output_all.json` (parsed full graph data, read by pre-training)
- `output_all.txt` (human-readable text version of the graph structure)
- `embedding_vocab.json` (feature vocabulary, used by both pre-training and embedding extraction)
- `vocab_freq_stats.txt` (frequency statistics per feature type)
- `parse_errors.csv` (records of WURCS that failed to parse)

### 2. `masktrain_windows_313.py`
The main MLM pre-training script. Reads `output_all.json` and `embedding_vocab.json` produced in the previous step, builds a `GlycanDataset`, randomly masks node/edge features, and trains a heterogeneous GAT (`HeteroConv + GATConv`) to predict the masked `anomeric_config`, `substituent`, `big_edge`, `small_edge_stereo`, `ring_bond` features. Uses CB Focal Loss, AdamW, ReduceLROnPlateau, and mixed-precision training. Products: `checkpoints/best_model_mlm.pt` (pre-trained model weights) and `error_analysis/training_log.txt`.

### 3. `deldownstata.py`
A data-leakage cleanup tool. Scans all CSVs under `downstreamstata/` to collect WURCS that appear there, then removes those rows from `dic.csv` to prevent downstream-evaluation samples from leaking into the pre-training/training set.

## Execution Order (main folder)

> The commands below assume the working directory is `MASK/` and Python 3.13 (the `_313` in the script name refers to 3.13). On Windows use `py -3.13`; on other platforms use `python`.

```bash
# Step 0. Place dic.csv (all glycan structures downloaded from the GlyTouCan database)

# Step 1. Clean data leakage: remove WURCS appearing in downstreamstata/ from dic.csv (rewrites dic.csv in place)
py -3.13 deldownstata.py

# Step 2. Parse WURCS → produces output_all.json / output_all.txt / embedding_vocab.json / vocab_freq_stats.txt / parse_errors.csv
py -3.13 wurcs_parser_reverse_edge.py

# Step 3. MLM pre-training → produces checkpoints/best_model_mlm.pt (reads output_all.json and embedding_vocab.json from Step 2)
py -3.13 masktrain_windows_313.py
```

After pre-training, downstream tasks (embedding extraction, classification training, metrics aggregation, etc.) run inside the `95/` folder — see "About the 95 folder" below.

## About the 95 folder

During pre-training, the checkpoint at **epoch 95 was the best model**, so all downstream tasks are built on this 95-epoch weight, and the related folders are uniformly named `95` / `95轮`. Under `95/`, subdirectories are organized by downstream task type, **each with its own README**:

| Subdirectory | Task | README |
|--------------|------|--------|
| `95/95轮tax/` | Taxonomy (8 levels) | [README](./95/95轮tax/README.md) |
| `95/95轮link/` | Glycan-linking | [README](./95/95轮link/README.md) |
| `95/95轮imm/` | Immunogenicity | [README](./95/95轮imm/README.md) |
| `95/taxall/` | Taxonomy "all-taxa" (incl. superkingdom, 9 levels) | [README](./95/taxall/README.md) |

> **Note**: In each subdirectory, `embedding_vocab.json` and `checkpoints/best_model_mlm.pt` are **moved in from the main folder** (the 95-epoch pre-training products), and `split_files/*.csv` or `train/*.csv` are external task data. These files are large or are generated products — not uploaded to GitHub; they must be placed manually before running. See each subdirectory's README for details.
