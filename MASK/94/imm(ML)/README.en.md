# imm(ML) — Immunogenicity downstream task

Using the **best checkpoint from epoch 94** of the main folder's pre-training, this task extracts embeddings for glycan immunogenicity data and trains a classifier.

> 🌐 中文版: [README.md](./README.md)

## Layout

```
imm(ML)/
├── masktrain_windows_313.py        # ⬅ moved in from the main folder (external)
├── wurcs_parser_reverse_edge.py     # ⬅ moved in from the main folder (external)
├── get_embeddings_W0.py            # extracts 1027-dim embeddings
├── glycanW0_classifier.py          # immunogenicity classification training
├── embedding_vocab.json            # ⬅ moved in from the main folder (external)
├── checkpoints/
│   └── best_model_mlm.pt          # ⬅ moved in from the main folder (epoch-94 weights, external)
├── train/
│   ├── imm_stata.csv               # ⬅ external input: raw immunogenicity data
│   ├── imm_stata_with_embeddings.csv  # generated by get_embeddings_W0.py
│   ├── classification_results/     # generated by glycanW0_classifier.py
│   └── 数量统计.py                  # counts rows and labels
```

> Files marked ⬅ are **moved in from outside**: `masktrain_windows_313.py`, `wurcs_parser_reverse_edge.py`, `embedding_vocab.json` and `checkpoints/best_model_mlm.pt` come from the main folder `MASK/`, and `train/imm_stata.csv` is the external immunogenicity dataset. These files are large or are generated products, so they are **not uploaded to GitHub** and must be placed manually before running.

## Data

Each row of `train/imm_stata.csv` is one glycan structure, with columns such as `glycan_id`, `glycan` (IUPAC), `species`, `immunogenicity` (0/1) and `wurcs`.

## Execution order

```bash
# Prerequisite: embedding_vocab.json and checkpoints/best_model_mlm.pt must be in this folder

# 1. Extract embeddings → train/imm_stata_with_embeddings.csv
py -3.13 get_embeddings_W0.py \
    --input_dir ./train \
    --output_dir ./train \
    --vocab_path embedding_vocab.json \
    --checkpoint_path checkpoints/best_model_mlm.pt

# 2. Classification training → train/classification_results/ (training_log.txt, confusion matrix, model, etc.)
#    Reads train/imm_stata_with_embeddings.csv by default; label column is immunogenicity
py -3.13 glycanW0_classifier.py
```
