# taxall — Taxonomy "all-taxa" configuration

Using the **best checkpoint from epoch 94** of the main folder's pre-training, this task extracts embeddings for glycans across all taxonomic levels (including superkingdom, 8 levels in total) and trains classifiers over multiple random seeds (1–10). This folder is the "all-taxa" extension of `94/tax(ML)` (superkingdom instead of domain); final training results are kept under `finaltrain/`, and graph-uncertainty outputs are under `uncertainty_graph/` at the root.

├── get_embeddings_W0.py            # extracts 1027-dim embeddings
├── 总结.py                          # aggregates F1/AUC across seeds
├── analyze_graph_uncertainty.py     # graph-uncertainty vs. correct/incorrect prediction analysis (run at root)
├── embedding_vocab.json            # ⬅ moved in from the main folder (external)
├── GlycanW0_metrics.csv            # generated by 总结.py
├── checkpoints/
│   └── best_model_mlm.pt          # ⬅ moved in from the main folder (epoch-94 weights, external)
├── split_files/                     # ⬅ external input: WURCS CSVs split by level (incl. superkingdom)
│   ├── superkingdom.csv / kingdom.csv / phylum.csv / class.csv
│   ├── order.csv / family.csv / genus.csv / species.csv
│   ├── 数量统计.py                  # counts rows and labels per CSV
│   └── result.txt                   # statistics output
├── split_files_processed_wurcs/     # generated by get_embeddings_W0.py (embedding CSVs)
├── uncertainty_graph/               # uncertainty outputs (figures + summary_table.json)
├── error_analysis/
└── finaltrain/                      # multi-seed final training (seeds 1–10)
    ├── 新建 文本文档.py             # batch-runs glycanW0_classifier.py in every seed folder
    ├── 1/                           # seed 1
    │   ├── glycanW0_classifier.py   # same as other seeds, only SEED differs
    │   └── split_files_processed_wurcs/  # ⬅ copied in manually from the top level
    │       └── training_results_<level>/  # per-level training outputs

> Files marked ⬅ are **moved in from outside**: `masktrain_windows_313.py`, `wurcs_parser_reverse_edge.py`, `embedding_vocab.json` and `checkpoints/best_model_mlm.pt` come from the main folder `MASK/`, while `split_files/*.csv` is external data split by taxonomic level. `finaltrain/<seed>/split_files_processed_wurcs/` is copied in manually from the top level. These files are large or are generated products, so they are **not uploaded to GitHub** and must be placed manually before running.

## Data

Each CSV under `split_files/` corresponds to one taxonomic level and contains columns such as `glytoucan_id`, `label` and `WURCS`. There are 8 levels: superkingdom, kingdom, phylum, class, order, family, genus, species (superkingdom replaces domain used in `94/tax(ML)`).

## Execution order

```bash
# Prerequisite: embedding_vocab.json and checkpoints/best_model_mlm.pt must be in this folder

# 1. Extract embeddings → split_files_processed_wurcs/*.csv
py -3.13 get_embeddings_W0.py \
    --input_dir ./split_files \
    --output_dir ./split_files_processed_wurcs \
    --vocab_path embedding_vocab.json \
    --checkpoint_path checkpoints/best_model_mlm.pt

# 2. Manually copy split_files_processed_wurcs/ into every seed folder under finaltrain
#    Each seed folder already contains its own glycanW0_classifier.py (same code, different seed)

# 3. Batch-run classification training for all seeds (recursively finds and executes every glycanW0_classifier.py)
cd finaltrain
py -3.13 "新建 文本文档.py"

# 4. Go back up and aggregate metrics across seeds → GlycanW0_metrics.csv
cd ..
py -3.13 总结.py

# 5. (Optional) graph-uncertainty analysis (run at this root; the script auto-detects seed folders under finaltrain/)
py -3.13 analyze_graph_uncertainty.py
```

## About finaltrain

`finaltrain/` holds the multi-seed final training results. `新建 文本文档.py` recursively finds and batch-executes every `glycanW0_classifier.py`; both `总结.py` and `analyze_graph_uncertainty.py` auto-detect numeric seed folders under `finaltrain/` (currently 1–10).

`analyze_graph_uncertainty.py` compares graph-structural uncertainty features (doubt-edge ratio, mean edge probability, anomer_x, stereo_x, etc.) between correctly and incorrectly classified samples, parses WURCS in multiple processes, aggregates per seed, draws 2x2 bar charts, and runs the Mann-Whitney U test. Outputs go to `uncertainty_graph/` at the root.
